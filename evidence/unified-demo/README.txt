Owned chain-1337 owner-bound conditional-TIMESTAMP validator regression, funded by the active EOA and paying its own test gas. Body frames make zero-value calls to that EOA with inert ABI-encoded uint256 arrays. The exact rejected signed payload is replayed locally against reconstructed validator/EOA code, balance and nonce with pinned genesis/client/policy. This is not a full public-chain snapshot; the public source commit/policy may differ. No roots, blobs, value transfers or storage reads are used by the frame recipe. Changing the validator mode from 1 to 0 skips TIMESTAMP and is the only correction beyond reduction. The public validator checks the protocol-validated canonical signature against its embedded owner; it remains an experimental test fixture, not a production wallet. Replay requires no private key. Rejection does not consume the validator nonce.
